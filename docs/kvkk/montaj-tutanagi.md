## 3. Kontrol listesi

- [ ] Kameralar **görünür**, gizlenmemiş
- [ ] **Mikrofon devre dışı** (fiziksel veya cihaz ayarı) — doğrulandı
- [ ] Kabin içi bilgilendirme etiketi yapıştırıldı
- [ ] Araç dışı bilgilendirme etiketi yapıştırıldı
- [ ] Kontak kablosu kontak hattına bağlandı (sürekli akıma **değil**)
- [ ] Kayıt ışığı / gösterge çalışıyor
- [ ] SD kart kayıt yapıyor, geri oynatma denendi
- [ ] Sistemde kabin kanalı `position: cabin` olarak tanımlandı
      (canlı izleme otomatik kapanır)
- [ ] Operatöre sistemin çalışma biçimi anlatıldı

## 4. Operatör beyanı

> Kameraların nereye baktığını montaj sırasında ekrandan gördüm. Kabin içi
> kameranın canlı izlenmediğini, yalnızca kaza/ani olay anında kaydın
> incelenebileceğini ve ses kaydı yapılmadığını biliyorum. Açı ayarına
> itirazım yoktur / itirazım aşağıdadır.
